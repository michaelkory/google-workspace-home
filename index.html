Private Google Workspace Integrations

This site describes personal integrations operated by Michael Kory Wilson. It is an informational website, not a public application or a Google sign-in service.

Hermes

Hermes uses Google authorization to work with the operator’s Google Drive files, Google Docs and Google Slides when requested. Access is limited by the permissions granted through Google and the operations the operator authorizes.

Private backups

A separate rclone OAuth client is being configured to support automated backups to the operator’s Google Drive. Restic encrypts backup contents before rclone transfers them. This backup integration is separate from the Hermes client.

Access and control

These tools are for the operator’s private use. This website does not provide access to the operator’s accounts, computers, files or backups. OAuth client secrets and tokens are not published here.

Google permissions can be reviewed or revoked through Google Account connections. Revoking access stops future API access; it does not automatically remove files or backups already stored.
