Privacy policy

This policy describes the private Google Workspace integrations operated by Michael Kory Wilson, including Hermes and the planned Restic/rclone backup integration. These integrations are not offered as a public multi-user service.

Google data accessed

With the operator’s authorization, the Hermes integration can access Google Drive file content and metadata and work with Google Docs and Google Slides. Actual access depends on the OAuth scopes granted and the requested task. The separate backup integration uses Drive access to store and retrieve encrypted backup repository objects.

How data is used

Google data is used to carry out the operator’s requested tasks and manage private backups. Data accessed through these integrations is not sold or used for advertising. It is not used by the operator to train general-purpose AI models.

When the operator uses Hermes to process Google content, relevant content may be sent to the configured AI model or other service providers as part of the requested task. This is distinct from a Restic backup: Restic encrypts backup contents before they are uploaded to Google Drive. This policy does not claim that all Hermes processing is local or that all downloaded working files are encrypted by Restic.

Storage and security

OAuth credentials and refresh tokens are kept in protected configuration on operator-controlled systems, with encrypted credential storage used for deployment where configured. They are not included in this public website or its repository. Operational data, working files and conversation records may remain on those systems according to their configured retention and backup policies.

Backup repository contents are encrypted by Restic. Google Drive still processes storage-related information such as object sizes and access activity. No storage or transmission method is guaranteed to be completely secure.

Retention, deletion and revocation

The operator controls retention and deletion of working files, records and backups. Deleting a source file does not necessarily remove older backup versions. Stored copies remain until the applicable retention policy or an explicit deletion removes them.

Authorization can be revoked through Google Account connections. Revocation prevents further authorized API access but does not automatically delete existing local records, Google Drive files or backups. The operator manages those separately.

This public website

This site has no login, submission form, advertising or custom analytics. It is hosted by GitHub Pages. GitHub records visitor IP addresses for security purposes; see the GitHub Privacy Statement.

Google API policy

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Contact

For non-sensitive questions, contact Michael Kory Wilson through the site’s issue tracker. Do not post passwords, OAuth credentials, tokens or private Google content in public issues.
